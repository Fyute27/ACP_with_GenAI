# CampusWheels Vehicle-Rental Desk

## How to Run

This program is written in Python.

Open the terminal in the `Assignment_02` folder and run:

```bash
python main.py
````

To run the tests, use:

```bash
pytest
```

## Files

* `rental.py` - Contains the Vehicle, Renter, ElectricCar, and Motorbike classes.
* `main.py` - Demonstrates renting, returning, validation, inheritance, and polymorphism.
* `README.md` - Contains the project information and instructions.
